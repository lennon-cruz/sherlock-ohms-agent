Setup

Running it

  • Get an OpenAI API key — create a free account at platform.openai.com, open the API keys page, and generate a new secret key
  • uv sync — install dependencies
  • cp .env.example .env — paste your key into .env (already gitignored — never commit or push it)
  • uv run ingest — downloads both reports and embeds them into local Chroma collections
  • uv run agent — interactive REPL, ask it anything

Never commit or push your OpenAI API key — keep it only in your local .env
